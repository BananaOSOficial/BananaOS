Sobre

O Banana Linux é um sistema linux baseado no arch que traz tema personalizado e, traz um novo comando, o banana que instala aplicativos AUR.

Como utilizar o comando banana:

Se você quiser instalar algo:

banana install nome-do-pacote

Se você quiser remover algum pacote AUR:

banana remove nome-do-pacote

Lembre de trocar o nome-do-pacote pelo pacote que você vai instalar/remover.
